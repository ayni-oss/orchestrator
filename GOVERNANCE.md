# Governance

This repository is private development and exploration. Maintainers set
technical direction, review changes, and make release decisions through pull
requests and issues.

Current requirements and delivery planning live in the private
[Ayni Orchestrator Project](https://github.com/orgs/ayni-oss/projects/2) and
linked repository issues. Completed delivery phases are retained as closed
GitHub milestones with their merged pull requests. Durable architecture,
operations, security, and contributor guidance remain in this repository.

Ayni must remain independently useful and must not depend on this repository.
When work spans both products, the private Orchestrator issue may link to a
public Ayni issue. The public issue must remain independently understandable and
must not reference or disclose private Orchestrator material.

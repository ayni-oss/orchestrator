# Documentation

Documentation has two audiences and two entry points.

| Reader | Start here | Contents |
| --- | --- | --- |
| People using Ayni Orchestrator | [User guide](site/index.md) · [orchestrator.ayni.build](https://orchestrator.ayni.build) | Setup, repositories, tasks, results and recovery |
| Contributors, operators maintaining deployments, and coding agents | [Technical documentation](technical/README.md) | Architecture, code boundaries, contracts, deployment procedures and research |

Only `docs/site/` is published by VitePress. Technical documents remain public
repository sources and are excluded from the website and its search index.
Requirements and delivery status belong in GitHub issues and the Project.

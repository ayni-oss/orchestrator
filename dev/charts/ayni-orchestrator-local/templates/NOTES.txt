The retained local development stack is installed in {{ .Release.Namespace }}.

Start or inspect the single development controller:
  cargo xtask dev
  cargo xtask dev status

Open http://127.0.0.1:5174. Debug logs and the pinned local runtime profile are
configured by the controller. Docker Desktop NetworkPolicy enforcement is not qualified.

Stop owned host processes and application controllers while retaining storage:
  cargo xtask dev stop

Do not create another namespace to recover from a development failure.
See docs/technical/operations/local-development.md.

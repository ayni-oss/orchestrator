# Managed task quality fixture

`source/` is a dependency-free Rust project with a real Ayni environment lock.
The lock is generated by Ayni 0.16.2; the native lock is generated by Cargo 1.94.0.
It enables tests and source size checks. `generate.py` packs the source with fixed
Git identity and timestamps. Regenerate using:

```sh
cargo generate-lockfile --manifest-path dev/fixtures/task-quality/source/Cargo.toml
ayni env lock --repo-root dev/fixtures/task-quality/source
python3 dev/fixtures/task-quality/generate.py
```

Build and load its local runtime with `dev/ctl quality-runtime`. This command
creates local images and a runtime identity file; it publishes no image. Use the
printed digest with the quality acceptance profile. The image uses Ayni's
unsigned local-consistency certificate profile, with no signing key or
trusted-builder identity. It still verifies protected runtime content, the
exact lock and platform, and dependency preparation through Ayni's entrypoint.

Coding remains the explicitly enabled deterministic file-proposal fixture. A
passing quality result establishes actual managed Ayni execution in the worker
runtime, source freezing, completion accounting and artifact retention. It does
not establish paid-provider behavior. The original `task-source` fixture retains
its synthetic lock and establishes coding isolation only.
